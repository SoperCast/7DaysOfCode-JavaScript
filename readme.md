Desafío 1: Operaciones Booleanas

Descripción

Este repositorio contiene la solución al primer desafío del reto #7DaysOfCode en JavaScript, donde se trabaja con operaciones booleanas y comparaciones de valores.

El objetivo de este ejercicio es corregir un código que compara valores en JavaScript de manera incorrecta debido a conversiones automáticas de tipos de datos. Se recomienda el uso de === en lugar de == para evitar problemas de tipado implícito.
